# Reference

Precise, factual lookup material. Reference pages describe what **is**, not
how to do a task. Everything here is generated from or verified against the
actual code.

* **[Configuration reference](configuration.md)** — every `config.yml` key,
  its default, and when to change it.
* **[Environment variables](environment.md)** — the `SOVEREIGN_*` env vars
  and how they map to config keys.
* **[CLI reference](cli.md)** — the `sovereign` command and its flags.
* **[HTTP / API reference](api/)** — endpoints grouped by protocol.

> **Status: scaffold.** Reference pages are populated from the live code in
> their implementation phases so they never drift ahead of reality.
